# Legacy GridZero contracts (not built)

Original GridZero V1–V4, ZeroToken and the zkVerify interfaces/mocks, kept for
provenance only. They are outside `src/` so Hardhat does not compile them
(they also no longer compile under solc 0.8.28 + viaIR).

Grood's live lineage is `src/GroodV2.sol` (+ `GroodTokenV2`, `drand/`).
